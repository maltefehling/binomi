Warum geht 2 : 0 nicht?
Teilen ist die Umkehrung von Malnehmen: 6 : 2 = 3, weil 3 · 2 = 6.
Für 2 : 0 = ? müsste also ? · 0 = 2 sein. Probiere eine Zahl für ? aus:

Jede Zahl mal 0 ergibt 0 – nie 2. Darum gibt es für 2 : 0 kein Ergebnis.

Merke: Definitionsmenge
Die Definitionsmenge D enthält alle Zahlen, die man für x einsetzen darf. Zahlen, bei denen ein Nenner 0 wird, gehören nicht dazu – denn für 2 : 0 müsste ? · 0 = 2 sein, und das schafft keine Zahl.
Hier: D = ℚ \ {0}
Lies: „alle rationalen Zahlen ohne die 0“ (ℚ = alle Brüche, Dezimalzahlen und negativen Zahlen).
