Tipps: Wie groß darf das Trainingsfeld werden?

Quadratisches Trainingsfeld, rundherum 3 m Sand. Die ganze Sandfläche ist ein Quadrat mit 196 m².

Öffne immer nur den nächsten Tipp – und versuche es danach erst wieder selbst.

  1. Innen liegt das Trainingsfeld mit der Seite x, rundherum 3 m Sand.
  2. Unten links: 3 m Sand.
  3. Dann kommt das Trainingsfeld: x.
  4. Unten rechts noch einmal 3 m Sand.
  5. Die ganze Seite der Sandfläche ist also 3 + x + 3 = x + ___ .
  1. Eine Seite der Sandfläche ist x + 6 lang.
  2. Die Sandfläche ist ein Quadrat: Die Seite links ist genauso lang.
  3. Fläche = Seite · Seite.
  4. Also: ( x + 6 ) · ( x + 6 ) = 196.
  1. Aus II.1a kennst du: x · x …
  2. … schreibt man kurz x².
  3. Genauso bei der Sandfläche: ( x + 6 ) · ( x + 6 ) …
  4. … schreibt man kurz ( x + 6 )². Die Gleichung heißt ( x + 6 )² = 196. Vergleiche mit der ersten Zeile von Tom und Lena.
Jetzt du: Schreibe deine Gleichung ins Skript. Schau dann, wie Tom und Lena weiterrechnen – wer kommt ans Ziel?
