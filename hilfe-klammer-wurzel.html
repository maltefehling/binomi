Tipp: Klammer im Quadrat

Beispiel mit anderen Zahlen: ( x + 2 )² = 49
( x + 2 )² = 49
Die Klammer ist ein Baustein. Nicht ausmultiplizieren!
x + 2 = 7 oder x + 2 = −7
Wurzel ziehen: √49 = 7. Zwei Fälle!
x = 5 oder x = −9
In jedem Fall − 2 rechnen.
Jetzt du: Bei dir steht eine andere Klammer und eine andere Zahl. Mach es genauso.
