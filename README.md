# binomi

Interaktive Seiten für Mathematik Klasse 8 (Realschule): Summen multiplizieren und die 1. binomische Formel.

- `index.html` – App „Die 1. binomische Formel am Quadrat“ (Stationen ① bis ③)
- `hilfe-vorstunde.html` / `checkliste-vorstunde.html` – Satzanfänge und Checkliste zum Erklär-Tandem „Summen multiplizieren“
- `hilfe-ub.html` / `checkliste-ub.html` – Satzanfänge und Checkliste zum Erklär-Tandem „1. binomische Formel“
